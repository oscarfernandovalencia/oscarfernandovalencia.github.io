Fundamentos Normativos AISC 360-16 / McCORMAC

1. Factores de Resistencia LRFD (Capítulo B)

De acuerdo con la especificación AISC 360-16 (y el Capítulo 2 de McCormac), los factores de reducción de resistencia aplicables son:

  • φt = 0.90 para fluencia en tracción bruta y φt = 0.75 para ruptura neta (Cap. D).
  • φc = 0.90 para compresión axial (Cap. E).
  • φb = 0.90 para flexión simple y biaxial (Cap. F).
  • φv = 0.90 para cortante (Cap. G).

2. Compresión Axial y Pandeo Local (Capítulo E)

La capacidad de diseño φc Pn se determina a partir del esfuerzo crítico Fcr:

Si KL/r ≤ 4.71 √(E / (Q × Fy)):
Fcr = Q × [0.658 ^ (Q × Fy / Fe)] × Fy  (Pandeo Inelástico)

Si KL/r > 4.71 √(E / (Q × Fy)):
Fcr = 0.877 × Fe  (Pandeo Elástico de Euler, Fe = π² E / (KL/r)²)

3. Flexo-compresión Combinada (Capítulo H1)

Para miembros sometidos simultáneamente a carga axial y momentos flectores en ambos ejes principales:

Para Pu / (φc Pn) ≥ 0.20 (Eq. H1-1a):
(Pu / φc Pn) + (8/9) × [ (Mux / φb Mnx) + (Muy / φb Mny) ] ≤ 1.00

Para Pu / (φc Pn) < 0.20 (Eq. H1-1b):
(Pu / 2 φc Pn) + [ (Mux / φb Mnx) + (Muy / φb Mny) ] ≤ 1.00

4. Espesor de Diseño para Perfiles A500

Según AISC 360-16 Sección B4.2, el espesor de pared de diseño para perfiles tubulares ASTM A500 producidos mediante soldadura por resistencia eléctrica (ERW) debe tomarse como tdes = 0.93 × tnom, lo cual previene subestimar los esfuerzos por tolerancias de laminación.
